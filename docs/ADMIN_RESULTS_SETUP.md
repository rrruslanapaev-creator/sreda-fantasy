# Включение админки и автоматического подсчёта

Эти изменения сделаны в ветке `feature/admin-scoring-nov-2026`. До слияния с `main` публичный сайт остаётся прежним.

## 1. Новые таблицы и функции (один раз)

В Supabase своего проекта открой **SQL Editor → New query**.

Скопируй содержимое файла [003_results_scoring.sql](../supabase/003_results_scoring.sql) из GitHub и выполни **Run**.

Миграция создаёт таблицы `player_round_stats`, `round_results_publication` и серверные SQL-функции. Старые менеджеры, PIN, составы, трансферы и футболисты **не удаляются**. Не запускай 002 повторно.

## 2. Назначить администратора

В **Supabase → SQL Editor** выполни запрос, заменив ВАШ_НИК на имя, под которым ты УЖЕ зарегистрировался на сайте:

```sql
UPDATE public.managers
SET is_admin = true
WHERE username_normalized = lower('ВАШ_НИК')
RETURNING username, is_admin;
```

Должна вернуться ровно одна строка с `is_admin = true`. Если строк нет, имя указано не так, как при регистрации. Не меняй PIN и не создавай аккаунт повторно.

## 3. Опубликовать обновлённый сайт

После применения SQL и назначения администратора слей рабочую ветку в `main` через pull request; Vercel автоматически развернёт новую версию. Обнови страницу, войди в свой аккаунт и найди вкладку **Админка**.

## 4. Внесение результатов

- Выбери тур. Он должен пройти дедлайн (20:30 Europe/Riga).
- Последовательно отметь присутствовавших футболистов и укажи индивидуальную статистику.
- В поле **«Пропущено командой за весь вечер»** укажи число голов, которое реальная команда данного футболиста пропустила за весь вечер. Это число нужно ввести **каждому** участнику этой команды. Сами команды создавать не нужно.
- Не присутствовавшим футболистам оставь флажок «Участвовал» выключенным — их баллы равны нулю.
- Нажми **«Сохранить статистику»**, затем **«Опубликовать очки»**. Сначала можно проверить предварительные очки на экране админки.
- Если результаты уже опубликованы, исправление и сохранение автоматически пересчитает очки менеджеров.

## 5. Принятые правила

- Присутствие +1.
- Гол: полевой +5, вратарь +10.
- Голевая передача +3.
- Сухой 10-минутный матч: полевой +1, вратарь +3.
- Отбитый пенальти +5, незабитый пенальти −2, автогол −2.
- Чемпион вечера +2.
- **За каждые два пропущенных гола команды за весь вечер −1 каждому присутствовавшему футболисту**, независимо от позиции. Число округляется вниз: 0–1 → 0; 2–3 → −1; 4–5 → −2; 6–7 → −3.
- Если основной полевой отсутствует, выходят присутствующие запасные по порядку 1, затем 2. Отсутствующий вратарь не заменяется.
- Присутствующий капитан получает вторую копию **всех своих очков**, включая отрицательные. Если капитан отсутствовал, бонус переходит присутствующему вице-капитану.
- Результаты текущего тура появляются в лиге только после публикации.

## Контроль

Рекомендуется проверить вручную один тестовый тур: футболист с 5 пропущенными должен получить −2, даже если он полевой. Проверить отсутствие основного, порядок выхода запасных, удвоение отрицательного результата капитана и совпадение общей суммы в лиге после повторной правки.

**Важно:** Нельзя удалять тестовый тур и чистить составы до согласованного перехода к официальному туру. Сброс теста и создание тура 18 ноября — отдельная операция, пока не автоматизированная.

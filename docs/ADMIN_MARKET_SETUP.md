# Управление рынком в админке

Новая возможность доступна только администратору — через вкладку **Админка → Игроки и цены**.

## Настройка

1. В Supabase SQL Editor выполни содержимое [004_admin_market.sql](../supabase/004_admin_market.sql) (один раз) **после 002 и 003**.
2. Убедись, что существующий аккаунт администратора имеет `is_admin = true`. Второй раз назначать его не нужно.
3. После проверки SQL-тестов можно объединить эту ветку в `main`, чтобы Vercel обновил сайт.
4. Войди на сайт как администратор, открой **Админка → Игроки и цены**.

## Добавление футболиста

Укажи имя, позицию **Полевой** / **Вратарь**, цену от 0.1 до 50.0 с шагом 0.1 и нажми **Добавить на рынок**. Имя должно быть уникальным без учёта регистра (дубликаты отклоняются). После сохранения футболист появляется на рынке, но не включается автоматически ни в один состав.

## Изменение стоимости

Найди футболиста по имени, впиши новую цену и нажми **Сохранить цену** напротив него. Цена меняется сразу на рынке. У существующих менеджеров уже приобретённые футболисты сохраняют **цену покупки**. При первом выборе/трансфере нового футболиста применяется его текущая цена. Это правило работает и между турами для футболиста, который остался в составе без продажи.

**Зачем миграция 004:** раньше сохранялся только список футболистов в составе, без цены покупки. Скрипт добавляет `roster_entries.purchase_price` и заполняет её для существующих составов по ценам на момент запуска миграции (старые исторические цены восстановить невозможно).

Миграция не удаляет аккаунты, составы, футболистов, очки и трансферы.

## Проверка

- Добавь тестового футболиста и убедись, что он появился в разделе «Рынок игроков».
- Измени его цену и проверь её на рынке после обновления страницы.
- Сохрани состав с игроком по старой цене, затем измени её и убедись, что стоимость **в сохранённом составе** осталась прежней.
- Если изменил цену у игрока, ещё не купленного менеджером, при новом включении в состав применяется новая цена.

Новое добавление игрока требует при следующем сохранении результатов закрытого тура указать его присутствие (для неигравшего — оставить «Участвовал» выключенным). Это не изменяет уже опубликованные очки до явного редактирования статистики.

Удаление футболистов специально не реализовано: оно может разрушить исторические составы и результаты. Управление активностью игроков можно добавить отдельно.
